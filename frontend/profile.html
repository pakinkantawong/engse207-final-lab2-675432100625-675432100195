Profile Studio

ปรับโปรไฟล์ให้พร้อมใช้งานจริง

หน้าโปรไฟล์นี้แยกจาก dashboard เพื่อให้แก้ไขข้อมูลส่วนตัวได้สะดวกขึ้น โดยยังใช้ token เดียวกับหน้าแรกและเชื่อมต่อกับ `user-service` โดยตรง.

กลับหน้า dashboard
ยังไม่ได้เข้าสู่ระบบ กรุณา login จากหน้า dashboard ก่อน
- เวลาที่อัปเดต profile ล่าสุด

ข้อมูลบัญชี

ข้อมูลชุดนี้แสดงจาก profile ที่ระบบสร้างไว้ให้โดยอัตโนมัติ

- Username
- Email
- Role
